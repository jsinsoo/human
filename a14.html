05 P versus NP P 대 NP

#041
P versus NP asks whether every problem whose solution can be checked efficiently can also be solved efficiently.
P 대 NP는 해답을 효율적으로 검증할 수 있는 모든 문제를 효율적으로 풀 수도 있는지를 묻는다.
#042
The class P contains decision problems solvable in polynomial time by a deterministic algorithm.
P는 결정론적 알고리즘으로 다항시간에 풀 수 있는 결정 문제들의 부류다.
#043
The class NP contains decision problems whose proposed solutions can be verified in polynomial time.
NP는 제안된 해답을 다항시간에 검증할 수 있는 결정 문제들의 부류다.
#044
Every problem in P is automatically in NP.
P에 속하는 모든 문제는 자동으로 NP에도 속한다.
#045
The great question is whether NP contains problems outside P.
핵심 질문은 NP에 P 밖의 문제가 존재하는가이다.
#046
If P equals NP, many hard search and optimization problems would become efficiently solvable in principle.
만약 P=NP라면 많은 어려운 탐색·최적화 문제가 원리적으로 효율적으로 풀릴 수 있게 된다.
#047
If P is not equal to NP, there are fundamental limits to efficient algorithmic discovery.
만약 P≠NP라면 효율적인 알고리즘적 발견에는 근본적인 한계가 존재한다.
#048
The problem affects cryptography, scheduling, verification, and many areas of computer science.
이 문제는 암호학, 일정 계획, 검증, 컴퓨터과학의 여러 분야에 영향을 준다.
#049
Most computer scientists believe that P is not equal to NP.
대부분의 컴퓨터과학자는 P와 NP가 같지 않을 것이라고 믿는다.
#050
But no accepted proof has established either equality or inequality.
그러나 어느 쪽도 아직 인정된 증명으로 확정되지 않았다.

06 Efficient Algorithms 효율적인 알고리즘

#051
An efficient algorithm is usually one whose running time grows polynomially with input size.
효율적인 알고리즘은 일반적으로 입력 크기에 따라 실행 시간이 다항식 수준으로 증가하는 알고리즘을 뜻한다.
#052
Polynomial-time growth is treated as a practical boundary between tractable and potentially intractable computation.
다항시간 성장은 보통 다룰 수 있는 계산과 매우 어려운 계산을 나누는 실용적 경계로 취급된다.
#053
A linear or quadratic algorithm often remains manageable as the input grows.
선형이나 이차 시간 알고리즘은 입력이 커져도 비교적 다루기 쉽다.
#054
An exponential algorithm can become unusable after only modest growth in input size.
지수시간 알고리즘은 입력 크기가 조금만 커져도 사용하기 어려워질 수 있다.
#055
P versus NP therefore asks about growth rates, not merely whether a problem can be solved eventually.
따라서 P 대 NP는 문제가 언젠가 풀리는지뿐 아니라 계산량이 어떻게 증가하는지를 묻는다.
#056
The distinction is central to modern complexity theory.
이 구분은 현대 계산복잡도 이론의 중심이다.
#057
Reductions allow mathematicians to compare the difficulty of different problems.
환원은 서로 다른 문제들의 난도를 비교하게 해 준다.
#058
NP-complete problems are among the most difficult problems in NP in this reduction sense.
NP-완전 문제는 이러한 환원의 의미에서 NP 안의 가장 어려운 문제들에 속한다.
#059
A polynomial-time algorithm for one NP-complete problem would imply polynomial-time algorithms for all NP problems.
NP-완전 문제 하나를 다항시간에 푸는 알고리즘이 발견되면 모든 NP 문제도 다항시간에 풀 수 있게 된다.
#060
This is why one breakthrough could transform the entire theory.
이 때문에 단 하나의 돌파구가 이론 전체를 바꿀 수 있다.
